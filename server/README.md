# Server — Voice AI Enabled Orchestration Engine (Gawah)

The Gawah FastAPI orchestration backend lives in [`../gawah-backend`](../gawah-backend).

```bash
# from repo root
.venv/bin/pip install -r gawah-backend/requirements.txt
.venv/bin/uvicorn app.main:app --app-dir gawah-backend --reload --port 8000
```
