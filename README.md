## Getting Started

### Prerequisites

- Node.js (LTS recommended)
- npm or pnpm
- API keys listed in `.env.example`

### Setup

```bash
# Install dependencies (once package manager is chosen)
npm install

# Copy environment variables
cp .env.example .env

# Start development
npm run dev
```
